# Learning Lens

Teacher and student dashboards for evidence-based learning: submit work, get feedback, track checkpoints, and manage flags.

## Structure

- **`frontend/`** — Next.js app (teacher dashboard, student dashboard, auth, evidence submission, feedback, Evidence Gallery).

## Quick start

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Features

- **Teacher:** Overview, classes, support; project detail with student progress, active flags, need help; send messages/guidance; assign to class.
- **Student:** Projects, submit work (checkpoints + evidence + rubric), view feedback, Evidence Gallery (per-checkpoint submissions matched to rubric).

## Tech

- Next.js, React, TypeScript, Tailwind CSS, shadcn/ui.
